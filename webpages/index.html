Akvim Terminal text editor

A lightweight text editor built from scratch in C++, using termios and raw system calls to drive the terminal directly — no curses, no abstraction layers.

Implements file I/O, syntax-aware cursor movement, a status bar, message prompts, and efficient text rendering with tab handling. A ground-up study in Unix system programming, memory management, and terminal escape sequences.

C++ termios Linux syscalls
